# Cloud Computing Reflection

Cloud computing has become an important part of my daily life because many of the applications I use rely on cloud technology. Three cloud services I frequently use are Google Drive, Facebook Messenger, and Canva.

Google Drive is an example of Software as a Service (SaaS) because it allows me to store, access, and share files online through a web browser without installing or managing any servers. It uses the Public Cloud deployment model because the service is available to anyone with a Google account.

Facebook Messenger is also a SaaS application since it provides messaging and video calling services over the internet. Like Google Drive, it operates on the Public Cloud because millions of users worldwide access the same cloud infrastructure.

Canva is another SaaS application that allows users to create graphic designs using a web browser. Canva is hosted in the Public Cloud, making it accessible from anywhere with an internet connection.

Version control is essential in cloud computing because cloud projects often involve multiple developers working on the same files. Without version control, changes could be lost or overwritten, making collaboration difficult.

Git and GitHub make teamwork easier by recording every change made to a project. They allow developers to review previous versions, restore files if mistakes occur, and merge updates from multiple contributors. GitHub also supports collaboration through branches, pull requests, and issue tracking, which help teams organize their work and improve project quality.

Through this course, I have learned that cloud computing is more than online storage. It includes different service models, deployment models, and collaboration tools that make modern software development faster, more reliable, and easier to manage.
