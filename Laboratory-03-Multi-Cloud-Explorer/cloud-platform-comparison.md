## Comparison Questions & Answers

1. **Which cloud provider offers the broadest range of services?**
   AWS offers the broadest selection of cloud services, spanning over 200 fully featured offerings ranging from fundamental compute to specialized edge solutions. Its long-standing market head start has allowed it to build the most extensive ecosystem available.

2. **Which provider best integrates with Microsoft technologies?**
   Microsoft Azure provides unmatched native integration with Microsoft software ecosystems, including Windows Server, Microsoft 365, and Active Directory. Organizations can also apply existing on-premises Microsoft licenses to cut running costs through Azure Hybrid Benefit.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**
   Google Cloud Platform (GCP) leads in AI and Kubernetes capabilities due to Google's role as the creator of Kubernetes and its continuous advancements in AI engineering. Services such as Google Kubernetes Engine (GKE) and Vertex AI provide best-in-class performance for containerized workloads and data analysis.

4. **Which cloud platform would you personally choose and why?**
   I would choose AWS for general application hosting due to its extensive maturity, vast documentation, and comprehensive community resources. However, for specialized data science projects or microservice management, GCP remains an exceptional alternative.
