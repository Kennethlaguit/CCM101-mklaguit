# Google Cloud Platform (GCP) Overview

## Brief Overview
Google Cloud Platform (GCP) was launched in 2008 and leverages Google's internal infrastructure expertise to deliver strengths in data analytics, AI/ML, and containerized operations.

## Global Infrastructure
GCP runs on 40+ regions and 120+ availability zones connected via Google’s private high-speed global fiber network.

## Cloud Management Console
The GCP Console features a clean interface organized by Google Cloud Projects, supported by the `gcloud` CLI tool and Google Cloud Shell.

![GCP Console](images/gcp-console.png)

## Four Core Services
* **Compute:** Google Compute Engine (GCE) - High-performance virtual machine instances.
* **Storage:** Cloud Storage - Unified object storage with high availability and low latency.
* **Kubernetes:** Google Kubernetes Engine (GKE) - Enterprise-grade managed Kubernetes container orchestration.
* **Big Data & AI:** BigQuery - Fully managed serverless cloud data warehouse.

## Three Advantages
1. **Data & AI Leadership:** Superior machine learning models, AI toolsets, and fast analytics using BigQuery.
2. **Kubernetes Native:** As the original creators of Kubernetes, GCP offers the most mature managed Kubernetes service (GKE).
3. **Global Private Network:** Fast, low-latency networking operating on Google’s backbone infrastructure.

## Typical Enterprise Use Cases
* Real-time big data processing and large-scale predictive analytics.
* Machine Learning model training and artificial intelligence deployments.
* Microservices development running on managed Kubernetes containers.
