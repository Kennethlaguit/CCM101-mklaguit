# Amazon Web Services (AWS) Overview

## Brief Overview
Amazon Web Services (AWS) launched in 2006 and is the market leader in public cloud computing. It provides a comprehensive, mature suite of cloud infrastructure and platform services.

## Global Infrastructure
AWS operates across 33+ Geographic Regions with over 105 Availability Zones (AZs) globally, interconnected with low-latency, high-throughput private network links.

## Cloud Management Console
The AWS Management Console provides a web-based graphical interface alongside the AWS CLI and Software Development Kits (SDKs) to provision and monitor infrastructure.

![AWS Console](images/aws-console.png)

## Four Core Services
* **Compute:** Amazon EC2 (Elastic Compute Cloud) - Scalable virtual servers.
* **Storage:** Amazon S3 (Simple Storage Service) - Scalable object storage.
* **Database:** Amazon RDS (Relational Database Service) - Managed relational database engines.
* **Networking:** Amazon VPC (Virtual Private Cloud) - Isolated cloud network environments.

## Three Advantages
1. **Market Maturity & Ecosystem:** Largest marketplace, extensive feature set, and deep community support.
2. **Global Reach:** Broad geographic presence ensuring localized hosting options.
3. **Flexible Pricing:** Deep tier discounts, Savings Plans, and Spot instances.

## Typical Enterprise Use Cases
* Hosting high-traffic web applications with dynamic auto-scaling.
* Enterprise data warehousing and big data analytics pipelines.
* Backup, disaster recovery, and long-term archiving solutions.
