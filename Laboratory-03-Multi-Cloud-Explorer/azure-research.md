# Microsoft Azure Overview

## Brief Overview
Microsoft Azure launched in 2010 and is a leading enterprise cloud platform designed for seamless integration with existing Microsoft software and services.

## Global Infrastructure
Azure boasts a global presence across 60+ regions, offering extensive availability zone support and specialized compliance-focused regions (e.g., Azure Government).

## Cloud Management Console
The Azure Portal features a customizable, tile-based web interface designed around Resource Groups, paired with Azure CLI and Cloud Shell.

![Linux OS](screenshots/azure-homepage,png.png)

## Four Core Services
* **Compute:** Azure Virtual Machines - On-demand, scalable computing instances.
* **Storage:** Azure Blob Storage - Massively scalable object storage for unstructured data.
* **Database:** Azure SQL Database - Fully managed relational database based on SQL Server.
* **Identity:** Microsoft Entra ID (formerly Azure AD) - Enterprise cloud identity and access management.

## Three Advantages
1. **Microsoft Ecosystem Integration:** Native compatibility with Windows Server, Active Directory, and Microsoft 365.
2. **Hybrid Cloud Dominance:** Strong hybrid cloud management via Azure Arc and Azure Stack.
3. **Enterprise Cost Savings:** Hybrid Benefit licensing allows reuse of existing on-premises Windows and SQL Server licenses.

## Typical Enterprise Use Cases
* Migrating traditional Windows Server and Active Directory environments to the cloud.
* Enterprise hybrid cloud deployments linking on-premises data centers to Azure.
* Development and deployment of enterprise .NET software solutions.
