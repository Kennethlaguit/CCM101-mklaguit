# Mission 10: The Enterprise Cloud Architect

## Project Overview

This project is the final laboratory activity for CCM101 - Cloud Computing.

The project demonstrates the design, deployment, security, automation, and documentation of a multi-tier containerized cloud infrastructure.

## Application Stack

- Ubuntu Server
- Docker
- Docker Compose
- WordPress
- MySQL
- UFW Firewall
- Bash
- Cron
- Docker Persistent Volumes

## Project Requirements

- Custom cloud architecture
- Ubuntu Server virtual machine
- Dockerized multi-tier application
- Persistent database storage
- UFW firewall
- Automated backup
- Cron scheduling
- Operational documentation
- Final reflection
