# Reflection

## What I Learned

In this laboratory, I learned how to access and use a Linux environment through KillerCoda. I practiced basic Linux commands for navigating the file system, managing users, creating directories, and gathering system information.

I also learned how Git and GitHub can be used to maintain a version-controlled Cloud Computing portfolio.

## Challenges Encountered

One challenge I encountered was becoming familiar with Linux commands and understanding how the Linux file system is organized. Creating a new user and managing user permissions also helped me understand basic Linux system administration.

Another challenge was organizing the laboratory files correctly and documenting the activities using Markdown.

## Importance to Cloud Computing

Linux is an important technology in cloud computing because many cloud servers and infrastructure environments use Linux-based operating systems.

Git and GitHub are also important because cloud engineers need to manage scripts, documentation, configuration files, and other technical resources using version control.

## Conclusion

This laboratory provided me with a foundation for working with Linux, cloud-based environments, documentation, and version control. The skills I learned will help me complete future Cloud Computing laboratory activities and develop better technical and system administration skills.
